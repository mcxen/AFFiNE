Welcome to AFFiNE development reference.

This document is intended for developers who want to contribute to AFFiNE. It contains information about the architecture of AFFiNE, how to build it, and how to contribute to it.

### Recent Feature Highlights

- **MCP (Model Context Protocol)**: Desktop app now includes built-in MCP server for AI integration
- **BYOK AI Support**: Configure custom AI providers with your own API keys
- **Bear Import**: Import notes from Bear app with full metadata preservation
- **Enhanced Markdown Export**: Folder-aware export with hierarchy preservation
